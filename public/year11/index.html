Real Functions (III)

Question 1

Question

The functions f and g are defined by

f(x)=2-x

with domain x≥0, and

g(x)=(x-2)2

for all x.

(a) Find the values of x for which

f(g(x))=x=g(f(x))

(b) Find f-1(x), giving its domain and range.

Solution (a)Show

First compute the two compositions.

Composition f ∘ g

g(x)=(x-2)2≥0 for all real x, so g(x) is always in the domain of f.

f(g(x))=2-x-22=2-|x-2|

Solve f(g(x))=x, i.e. 2-|x-2|=x, or |x-2|=2-x.

Case 1: x≥2. Then |x-2|=x-2, so

x-2=2-x⇒2x=4⇒x=2

which satisfies x≥2.

Case 2: x<2. Then |x-2|=2-x, so

2-x=2-x

which is true for every x<2.

Hence f(g(x))=x for all x≤2.

Composition g ∘ f

g(f(x)) is defined only for x in the domain of f, i.e. x≥0.

g(f(x))=(f(x)-2)2=(2-x-2)2=(-x)2=x

So g(f(x))=x for every x≥0.

Both conditions together

We need f(g(x))=x and g(f(x))=x. That requires x≤2 (from f∘g) and x≥0 (from g∘f).

Answer: 0≤x≤2 (i.e. x∈[0,2]).

Solution (b)Show

Domain of f: [0,∞). As x goes from 0 to ∞, x goes from 0 to ∞, so f(x)=2-x goes from 2 down to -∞. Thus range of f is (-∞,2].

Set y=f(x)=2-x.

x=2-y(requires 2-y≥0, i.e. y≤2)

x=(2-y)2

Swapping variables:

Answer: f-1(x)=(2-x)2

Domain of f-1: (-∞,2] (range of f)

Range of f-1: [0,∞) (domain of f)

Note: f-1 has the same formula as g, but its domain is restricted to (-∞,2].

Question 2

Question

The transformation h is defined by

h:(x,y)↦(x+3,2y)

What is h-1(x,y)?

SolutionShow

h sends x to x+3,2y. To invert, undo the operations in reverse order:

1. Undo the vertical stretch: divide the second coordinate by 2.

2. Undo the horizontal shift: subtract 3 from the first coordinate.

If h(x,y)=(u,v)=(x+3,2y), then x=u-3 and y=v/2. Renaming u as x:

Answer: h-1(x,y)=x-3,y2

h(h-1(x,y))=hx-3,y2=((x-3)+3,2·y2)=(x,y)

Question 3

Question

Find the coordinates of the crossing points between y=f(x)=(x-1)2 for x≤1 and its inverse function, using:

(a) a graphical method

(b) an algebraic method.

SolutionShow

First find the inverse.

f(x)=(x-1)2 with domain x≤1.

Range of f: as x→-∞, f(x)→∞, and f(1)=0, so range(f)=[0,∞).

Set y=(x-1)2 with x≤1. Then y=|x-1|=1-x, so x=1-y.

Therefore f-1(x)=1-x, with domain [0,∞) and range (-∞,1].

(a) Graphical methodShow

Sketch y=f(x) (the left branch of the parabola with vertex 1), y=f-1(x) (reflection of that graph in y=x), and the line y=x.

The two graphs meet at three points: 0, 1, and the point on y=x in the first quadrant.

(b) Algebraic methodShow

Both graphs are defined for x in Dom(f)∩Dom(f-1)=(-∞,1]∩[0,∞)=[0,1]. Solve f(x)=f-1(x) on this interval:

x-1)2=1-x

Let t=x≥0. Then x=t2 with t∈[0,1], and

t2-1)2=1-t

1-t2)2=1-t

1-t)2(1+t)2=1-t

If t=1, then x=1: f(1)=0 and f-1(1)=0, so 1 is a crossing point.

If t≠1, divide by 1:

(1-t)(1+t)2=1

(1-t)(1+2t+t2)=1

1+2t+t2-t-2t2-t3=1

t-t2-t3=0

t(1-t-t2)=0

So t=0, or t2+t-1=0 ⇒ t=-1±52.

The only root in 0 is t=-1+52.

t=0⇒x=0: f(0)=1 and f-1(0)=1, so 0 is a crossing point.

t=-1+52⇒x=t2=-1+522=3-52

At this x-value, f(x)=x (equivalently solve x-1)2=x on 0), so the crossing point lies on y=x:

3-52

Answer: The crossing points are 0, 1 and 3-52.

Question 1

Question

Determine how the curve y=x3-x must be stretched in order to obtain the graph of y=x3-3x.

SolutionShow

Start with y=x3-x. After a stretch of factor a parallel to the x-axis and factor b parallel to the y-axis, the equation becomes

y=bxa3=ba3x3-bax

We need this to match y=x3-3x, so

ba3=1,ba=3

From the second equation, b=3a. Substitute into the first:

3aa3=1⇒3a2=1⇒a2=3⇒a=3

(taking the positive scale factor). Then b=33.

Check:

y=33x33=33x333=x3-3x

Answer: Stretch by factor 3 parallel to the x-axis, and by factor 33 parallel to the y-axis.

Question 2

Question

A cosine curve has an amplitude of 5 and a period of 3π. It has a minimum value of 5 at x=0. Find its equation in the simplest form.

SolutionShow

Use the form y=Acos(Bx)+D.

Amplitude 5 ⇒ |A|=5.

Period 3π=2πB ⇒ |B|=23.

Minimum value is 5, so D-|A|=5 ⇒ D-5=5 ⇒ D=10.

At x=0 the curve is at a minimum. Standard cosine has a maximum at 0 when A>0, so take A=-5:

y=-5cos2x3+10=10-5cos2x3

Check: y(0)=10-5=5 (minimum), period 2π23=3π, amplitude 5.

Answer: y=10-5cos2x3

Question 3

Question

Sketch 2xy-3x-y-2=0 and show that it is a rectangular hyperbola.

SolutionShow

Rewrite in standard form

2xy-3x-y-2=0

2xy-3x-y=2

Add 3/2 to both sides to factorise:

2xy-3x-y+32=72

(2x-1)y=72

xy=74

This is the translated form of XY=c with c=74>0.

Why it is rectangular

Asymptotes: x=12 and y=32.

These are vertical and horizontal, so perpendicular. A hyperbola with perpendicular asymptotes is a rectangular hyperbola.

Centre: 12.

Sketch points

x-intercept (y=0): -23,0.

y-intercept (x=0): 0,-2.

Since the product is positive, the branches lie where x-12 and y-32 have the same sign (top-right and bottom-left relative to the asymptotes).

Answer: xy=74, with perpendicular asymptotes x=12 and y=32, hence a rectangular hyperbola.

Real Functions (V)

Question 1

Question

Given that f(x)=x2-2x-3.

(a) Sketch y=f(x), showing all intercepts with the axes.

(b) Using the graph of y=f(x) and any other appropriate graphs, sketch y=sin[f(x)].

Solution (a)Show

Factorise: f(x)=(x-3)(x+1).

x-intercepts: x=-1, x=3 ⇒ -1,0, 3.

y-intercept: f(0)=-3 ⇒ 0,-3.

Parabola opening upwards; vertex at x=1: f(1)=-4 ⇒ 1,-4.

Solution (b)Show

For each x, compute f(x) then take sin of that value. The range of sin is always -1,1.

Zeros of the composite occur when f(x)=nπ (n∈Z); in particular at x=-1 and x=3 where f=0.

Between x=-1 and x=3: f(x) goes from 0 down to -4 then back to 0, so sin[f(x)] traces a continuous curve in -1,1 (near the vertex, sin(-4)≈0.76).

Outside -1,3: f(x)→+∞ as x→±∞, so sin[f(x)] oscillates between -1 and 1, with oscillations becoming faster as x increases (since f(x) grows like x2).

Question 2

Question

Given that f(x)=1-x2.

(a) Sketch y=f(x) showing all important features.

(b) Sketch the graph of y=ln[f(x)] and hence the graph of y=1ln[f(x)], using the previous graph and any other appropriate graphs.

Solution (a)Show

f(x)=1-x2 is a downward-opening parabola.

Vertex: 0.

x-intercepts: 1-x2=0 ⇒ x=±1 ⇒ -1,0, 1.

y-intercept: 0.

Solution (b)Show

Graph of y = ln[f(x)]

Domain: f(x)>0 ⇒ 1-x2>0 ⇒ |x|<1.

On -1,1, 0<f(x)≤1, so ln[f(x)]≤0.

At x=0: ln(1)=0 (maximum).

As x→±1-: f(x)→0+, so ln[f(x)]→-∞. Vertical asymptotes x=±1.

Graph of y = 1 / ln[f(x)]

Domain: |x|<1 and ln[f(x)]≠0, so x≠0. Thus domain is -1,0)∪(0,1.

Since ln[f(x)]<0 on this domain, y=1ln[f(x)]<0.

As x→0: ln[f(x)]→0-, so y→-∞ (vertical asymptote x=0).

As x→±1-: ln[f(x)]→-∞, so y→0-.

Question

The curve y=2x is approximated by the parabola y=ax2+bx+c for -1≤x≤1. The values of constants a, b and c are chosen so that the two curves intersect at x=-1,0,1.

(a) Find the values of the constant coefficients.

(b) Use this parabola to estimate the values of 2 and 12.

(c) Compare the values found in part (b) with the values obtained by a calculator. Show that the percentage errors are approximately 1.6% and 2.8% respectively.

Solution (a)Show

The curves meet when 2x=ax2+bx+c at x=-1,0,1.

x=0: 20=1=c ⇒ c=1.

x=1: 2=a+b+1 ⇒ a+b=1.

x=-1: 12=a-b+1 ⇒ a-b=-12.

a+b=1

a-b=-12

2a=12⇒a=14,b=34

Answer: a=14, b=34, c=1, so y=14x2+34x+1.

Solution (b)Show

2=212: put x=12.

y=14122+3412+1=116+38+1=2316=1.4375

12=2-1/2: put x=-12.

y=14122+34+1=116-38+1=1116=0.6875

Estimates: 2≈2316, 12≈1116.

Solution (c)Show

Calculator: 2≈1.41421356, 12≈0.70710678.

Percentage error for 2:

1.43751.41421356×100%≈1.65%≈1.6%

Percentage error for 12:

0.68750.70710678×100%≈2.77%≈2.8%

Hence the percentage errors are approximately 1.6% and 2.8% respectively.

Question 1

Question

(a) Sketch a graph of the function y=x-1)(x+2x(x+4).

(b) Prove that the roots of the equation kx(x+4)=(x-1)(x+2) are always real.

(c) How can you establish this result from the graph you have drawn?

Solution (a)Show

Let f(x)=x-1)(x+2x(x+4).

Vertical asymptotes: x=0, x=-4.

x-intercepts: x=1, x=-2 ⇒ 1, -2,0.

Horizontal asymptote: degrees equal, so y=1.

Crossing of y=1: solve x-1)(x+2)=x(x+4 ⇒ x=-23, so the graph crosses at -23,1.

Solution (b)Show

kx(x+4)=(x-1)(x+2)

kx2+4kx=x2+x-2

(k-1)x2+(4k-1)x+2=0

Case 1: k=1.

3x+2=0⇒x=-23

which is real.

Case 2: k≠1.

Discriminant:

Δ=(4k-1)2-8(k-1)=16k2-8k+1-8k+8=16k2-16k+9

Δ=16k2+5≥5>0

So there are two distinct real roots.

Hence for every real k, the equation has real root(s).

Solution (c)Show

For x≠0,-4, the equation is equivalent to f(x)=k.

From the graph in (a), every horizontal line y=k meets the curve at least once (the three branches, with vertical asymptotes and horizontal asymptote y=1, cover all real k). Therefore f(x)=k always has a real solution, which is the graphical form of the result in (b).

Question 2

Question

Graph the region: 1x>1y.

SolutionShow

Domain: x≠0, y≠0 (axes excluded).

1x-1y>0⇒y-xxy>0

So (y − x) and xy have the same sign:

• xy>0 and y>x (quadrants 1 and 3, above the line y=x);

• xy<0 and y<x (quadrants 2 and 4, below the line y=x).

The boundary y=x (with x≠0) is not included, since the inequality is strict. The axes are not included.

Question 3

Question

Let P(x,y) be a point, L1 be the line y=m1x+b1 and L2 be the line y=m2x+b2. Let C be the set of all points P such that the sum of the squares of the distances of P from L1 and L2 is r2. Prove that C is a circle if and only if L1 and L2 are perpendicular.

(Hint: Find an expression for the locus in terms of x,y,m1,m2,b1,b2 and then prove that the xy term equals 0.)

SolutionShow

Distance formulae

Rewrite the lines as m1x-y+b1=0 and m2x-y+b2=0. Then

d1=m1x-y+b1m12+1,d2=m2x-y+b2m22+1

The condition d12+d22=r2 becomes

m1x-y+b12m12+1+m2x-y+b22m22+1=r2

Expand to a general conic

Let A=m12+1 and B=m22+1. Expanding gives a conic

ax2+2hxy+by2+2gx+2fy+c=0

with

a=m12A+m22B,b=1A+1B,2h=-2m1A

For this conic to be a circle we need a = b and h = 0 (equal coefficients of x² and y², and no xy term).

Condition h = 0

m1A+m2B=0

m1(m22+1)+m2(m12+1)=0

(m1+m2)(m1m2+1)=0

So m1=-m2 or m1m2=-1.

Condition a = b

a-b=m12-1m12+1+m22-1m22+1

If m1m2=-1 (and m1≠0), then m2=-1/m1. Substituting yields a=1 and b=1, so a=b.

If instead m1=-m2 but m1m2≠-1, then a=2m12m12+1 and b=2m12+1, so a=b only when m12=1, which forces m1m2=-1 again.

Hence C is a circle ⟺ the lines are perpendicular

(⇒) If C is a circle, then h=0 and a=b, which together force m1m2=-1. Thus L1 and L2 are perpendicular.

(⇐) If L1 and L2 are perpendicular, then m1m2=-1, so h=0 and a=b. The locus equation becomes

x2+y2+Dx+Ey+F=0

for suitable D,E,F (depending on m1,m2,b1,b2,r), which is the equation of a circle.

Therefore C is a circle if and only if L1 and L2 are perpendicular.
